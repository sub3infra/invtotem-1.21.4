# Inventory Totem (Fabric, Minecraft 1.21.4)

Moves a Totem of Undying into your offhand whenever you open your inventory.
Open settings with Right Shift (rebindable) or via Mod Menu.

Build: push to GitHub, open the Actions tab, download the `invtotem-jar` artifact.
Requires Fabric Loader 0.18+ and Fabric API. Mod Menu is optional.
